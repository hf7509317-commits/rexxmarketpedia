GANTI FOTO PROFIL TOKO

1. Siapkan foto profil toko, misalnya profile.jpg atau profile.webp.
2. Simpan foto tersebut di folder ini.
3. Buka src/store.config.js.
4. Ubah nilai profileImage, contoh:
   profileImage: "/assets/profile.jpg",
5. Restart server.

File reference.png adalah gambar referensi yang diberikan saat pembuatan project dan tidak dipakai sebagai foto profil default.
